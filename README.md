# Электронное расписание для группы ПИ-17 из ЮФУ

Приложение расположено [тут](https://sfedu-pi17.github.io/)

## Особенности

- Поддержка светлой и темной тем
- Адаптивный дизайн
- Цветовая индикация изменений расписани

## Запуск на локалке

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5174

## Технологии

- React 19.2.8
- Mantine UI
- Vite
