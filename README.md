# Электронное расписание для группы ПИ-17 из ЮФУ

Приложение для отображения расписания занятий из Google Sheets с modern UI от Mantine.

## Особенности

- Поддержка светлой и темной тем
- Адаптивный дизайн
- Модерн UI компоненты от Mantine
- Цветовая индикация типов занятий

## Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5174

## Технологии

- React 19.2.8
- Mantine UI
- Vite
